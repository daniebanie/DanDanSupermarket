Dit project is een supermarktsimulatie geschreven in IntelliJ IDEA Java.
In de simulatie worden er customers gespawnd, die een boodschappenlijstje
meekrijgen en vervolgens bij de bijpassende shelves langs gaan om artikelen
in hun winkelmandje te stoppen. Vervolgens gaan ze naar de kassa, waar hun
artikelen worden afgerekend. Tegelijkertijd zijn er vakkenvullers, die de
leeglopende vakken weer bijvullen.
